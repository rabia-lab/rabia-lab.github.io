Software & Data

Open-source software and data-driven tools supporting reproducible and scalable agricultural research.

  • Hailo Ag Model Zoo — Crop & Weed Detection

    Deployment-ready crop and weed detection models (YOLOv8, YOLOv10, and YOLOv11) compiled for Hailo-8 and Hailo-8L edge accelerators, so they run efficiently on low-power hardware such as a Raspberry Pi 5. Accompanies our Frontiers in Agronomy paper on edge-AI weed detection.

    Hugging Face GitHubPaper Model DOI MIT
